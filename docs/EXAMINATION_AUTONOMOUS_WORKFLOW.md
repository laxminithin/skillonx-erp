# Examination Autonomous Workflow

Configured by `college_examination_governance.governance_type = AUTONOMOUS`.

Autonomous institutions may use SkillonX as the institutional examination source of truth for owned workflows.

Supported now:

- Exam creation and lifecycle status updates.
- Subject scheduling with conflict detection.
- Eligibility computation.
- Room allocation, seating generation, and seat locking.
- Invigilation assignment with conflict detection.
- Marks entry, import dry run, import commit, submit, verify, lock, unlock, and moderation.
- Result processing with grade/SGPA calculation.
- Result publication and student result visibility.
- Student revaluation request and Finance demand hook.
- COE readiness dashboard.

Required workflow still incomplete:

- Formal registration application/approval/freeze.
- Complete QP setter/scrutiny/moderation/secure-release lifecycle.
- Exam-day attendance/Form-A freeze.
- MPC case engine.
- Strong room, answer book, and script custody ledgers.
- Digital valuation with anonymous/dummy numbering.
- Result version recalculation for revaluation/correction.
- Grade cards/transcripts with document numbers and QR verification.
- Remuneration claims.
