## New work required this phase (the only two genuine gaps)

1. **GRN idempotency** — add an optional `idempotencyKey` to `grnSchema`; `createGrn` checks-then-inserts inside the existing PO-row-locked transaction (reusing the lock that's already there, no new locking machinery) and returns the prior GRN unchanged on replay instead of re-posting stock.
2. **Asset handoff integration** — a new Procurement-owned function that, for an `ASSET_TRACKABLE` GRN line, calls the frozen P0.2 `registerAsset()` once per accepted unit and records the linkage in a new, Procurement-owned join table keyed uniquely per GRN item, so replay returns the existing handoff instead of creating duplicate assets. **P0.2's own code and schema are not modified.**
