How to run each shot

  • Frame in, prompt in. Upload the matching panel_0X.png as the start image, paste the motion prompt into the text field and the negative prompt into the negative field. The image carries the look; the prompt carries only the motion.
  • Runway Gen-4: use the panel as the reference image, keep motion low. If it drifts, shorten the prompt to just the first sentence.
  • Kling: use Image-to-Video, add the girl's face under "Elements" for shots 3–12 so she stays the same child throughout.
  • The dialogue shots (9–11) only need the mouth to move — record the VO separately and sync in the edit. Don't expect the model to lip-sync your words.
  • Two takes minimum per shot; keep the calmest. Over-animated is the usual failure mode for a gentle story like this.
