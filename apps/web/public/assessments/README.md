# Assessments

Subject-wise quiz and assignment banks aligned to every classroom module.

## What you get

- **Quiz** (`quiz.md`): **at least 50** multiple-choice questions per module. Each item has four options, the correct answer, a short explanation, and a difficulty tag (`Easy` / `Intermediate` / `Difficult`). A quick answer key is at the end of each file.
- **Assignment** (`assignment.md`): **40** questions per module (descriptive, use-case, analytical, design) with marks, difficulty, question type, primary CO, and expected key points. Faculty pick a subset for one CIE assignment.

Folder layout: `assessments/<Subject>/<Module-or-Unit>/quiz.md` and `assignment.md`.
